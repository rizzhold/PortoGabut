## 📸 Highlights & Features

- **🎨 Material Expressive UI Design**: Smooth micro-interactions, pill-shaped buttons, asymmetrical cards, and bouncy spring animations using `cubic-bezier`.
- **🌗 Adaptive Dual-Theme System**:
  - **Light Mode**: Neon Cyan/Blue glow effect (`box-shadow`).
  - **Dark Mode**: Cyberpunk Green glow effect for system modders.
- **💻 Dual-Slide Console Widget**:
  - **Slide 1 (Logcat Terminal)**: Interactive random status log generator (`[INFO]`, `[SUCCESS]`, `[FAIL]`).
  - **Slide 2 (Daily Story)**: Developer diary colongan / curhat gabut seputar dunia ngomprek.
- **🚀 Showcase Gallery**: Grid layout with category filters (ROMs, Recovery, Mods).
- **📱 Responsive Navigation**: Material 3 Top App Bar with segmented tabs (`Home`, `About Me`, `My Activity`).
